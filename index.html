LEDネームバッジ 書き換えツール

Shigezone で販売している LEDネームバッジ（11×44ドット、USB ID 0416:5020）を、パソコン版の Chrome / Edge から書き換えます。

このブラウザは WebHID に対応していないため、バッジに書き込めません。パソコン版の Chrome または Edge で開いてください（スマホ・タブレット・Safari・Firefox は非対応）。

プレビュー

USBでバッジを接続し「バッジに書き込む」を押してください。

対象のLEDバッジ

  • 商品: LEDネームバッジ（Shigezone）
  • 表示: 縦11×横44ドットのLED（漢字は1画面に最大4文字）。USB Type-C で充電・書き換え
  • USB ID 0416:5020（"LS32 Custm HID" などと表示される）。同じIDの同型バッジでも動く可能性がありますが、未確認です

対応ブラウザ

ブラウザからUSB機器を操作する WebHID という機能を使うため、対応しているブラウザでしか動きません。

  • ○ パソコン（Windows / Mac / Linux / Chromebook）の Chrome・Edge（Linux は udev の設定が必要。README参照）
  • × Firefox、Safari、スマートフォン・タブレットのブラウザ（Android の Chrome を含む）

バッジ本体の操作

  • 電源ボタン：長押しでオンオフ。USB給電時にはオンまたはバッテリ残量表示になる。短く押すことで明度4段階切替
  • 選択ボタン：8種類までのメッセージ＆エフェクトを入力でき、このボタンでどれを表示するか選択できる
— Shigezone の note より引用

使い方・注意

  • 初回は「バッジに書き込む」を押すと機器選択ダイアログが出ます。「LS32 Custm HID」などを選んで「接続」。
  • バッジによっては電源ON＋USB接続中のみ認識されます。認識されないときはケーブル（データ通信対応）や電源を確認してください。
  • Linux では udev ルールが必要です（README参照）。
  • 非公式ツールです。動作は保証できません。自己責任でお使いください。
